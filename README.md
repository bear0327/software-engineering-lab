## 查看和编辑

1. 阅读提交目录中的 `实验报告.pdf`。
2. 用 PlantUML 打开 `UML/*.puml`；PNG 为该源代码的渲染结果。
3. 用 diagrams.net（draw.io）打开 `制作源文件/酒店预订UI.drawio`，每个页面包含可单独编辑的矢量控件，不是整页截图。
4. 用浏览器打开 `制作源文件/交互原型.html`，切换页面并体验查询、下单、修改、取消、确认和入住等演示流程。所有数据仅为原型示例，不连接业务后端。

## 重新生成

Python 3.12；依赖：`pillow reportlab playwright pymupdf`；本机 Chrome；Java 8+；PlantUML 1.2024.8。

```powershell
python 制作源文件/build.py --plantuml "C:\路径\plantuml.jar"
python 制作源文件/check.py
```

PDF 和 PNG 属于可重建产物，默认不进入 Git；源稿、UML、UI 控件数据及审查记录进入 Git，便于清楚比较设计修改。打包仅包含课程要求的 PDF、PNG 和 PUML，不夹带 `.git`、缓存或构建脚本。
